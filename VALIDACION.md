# Validacio.
**Alumne:** Pol Plana i Boivin.

## Descripció del projecte
Prova de validació UP1-Biblioteca API amb documentació en mkdocs en github pages y openapi.

## Diferencies entre Commit y Push.
**Commit:** Aplica els cambis de la "staged area" al repositori local.
**Push:** Aplica els **commits** realitzats al repositori local al repositori de github.

## Ramas
He integrado tanto la rama feature/docs como la feature/openapi, haciendo uso de git merge que sirve para juntar el contenido de la rama especificada en el comando con la que esta seleccionada.
