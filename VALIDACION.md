# Validacio.
**Alumne:** Pol Plana i Boivin.

## Descripció del projecte
Prova de validació UP1-Biblioteca API amb documentació en mkdocs en github pages y openapi.

## Diferencies entre Commit y Push.
**Commit:** Aplica els cambis de la "staged area" al repositori local.
**Push:** Aplica els **commits** realitzats al repositori local al repositori de github.

## Rames
He integrat tant la rama feature/docs com la feature/openapi, fent ús de git merge que servix per a juntar el conteningut de la rama especificada en el comandament amb la que esta seleccionada.

## Desplegament
Pàgina de mkdocs desplegada en: [Biblioteca API]( https://polplana.github.io/validacion-up01/)
La rama generada conte la documentació de la API de Biblioteca a través de mkdocs preparada per a el despleguament en github pages gracies al comandament mkdocs gh-deploy.
